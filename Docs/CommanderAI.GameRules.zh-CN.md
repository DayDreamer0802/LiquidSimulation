# 指挥官 AI：基础游戏规则

本文件帮助大模型理解游戏。它不是运行时配置；塔楼数值以 `Assets/Resources/Config/tower_defense_balance.json` 和游戏代码为准，关卡内容以实际地图资源为准。

## 一局游戏在做什么

- 敌人从多个生成点进入地图并向主塔移动。普通敌人接触主塔会造成伤害并离场；Boss 抵达主塔会直接导致失败。
- 在可建造格上购买塔楼，用击杀获得的金币继续建造或升级。主塔被摧毁则失败，达到关卡胜利条件则胜利。
- 默认关卡的核心胜利条件是击杀 Boss。Boss 在第 12 分钟出现；第 3、4.5、7、10、15 分钟还会触发关卡事件。
- 敌人会随游戏时间成长。精英敌人更强，默认关卡前三分钟不生成精英。

## 塔楼与升级

- 合法塔楼 ID 为 `0..9`。`0..7` 是主力塔，`8` 是充能塔，`9` 是强化塔。
- 主力塔最高 3 级。冰塔、机枪塔、加农炮、火焰塔、激光塔在升 2 级时选择路线，升 3 级时再选择该路线的一项强化；穿透激光、水晶塔、火箭齐射为线性升级。
- 充能塔和强化塔不能升级。充能塔可把相邻的一个普通可建造格改成随机三选一的特殊格；强化塔为一格范围内的塔楼提供可叠加的全属性强化。
- 主力塔可切换“终点最近”与“Boss 优先”索敌。Boss 出现后应把适合单体输出或削甲的塔切到 Boss 优先；机枪、激光、火焰的集中模式带有各自代价，详见塔楼参考 JSON。

## 地图格与组合

- 特殊建造格会改变伤害、范围、攻速、升级价格、金币收益或攻击方式。属性等级每级通常代表 `20%`，最终有效等级限制为 `-3..5`。
- 霜寒格使塔楼的非持续直接伤害附加减速：单体直接伤害为 `20%`，范围、锥形和直线直接伤害减半为 `10%`；持续伤害不触发。
- 冰塔可制造霜寒格、施加冻结或脆弱；爆燃火塔可消耗冻结触发高额爆燃。激光破甲、冰塔脆弱与其他输出塔适合协同。
- 充能塔的位置要同时考虑自身可放置点、相邻目标格和准备在该格建造的塔，不能只按即时伤害判断。

## 经济与决策原则

- 金币用于建造、升级、充能塔刷新和部分战术技能。卖塔通常只返还累计投入的一部分；某些地图格会改变返还或升级价格。
- 不要只比较面板 DPS：范围伤害、控制、破甲、Boss 火力、敌人离主塔的距离、特殊格收益和未来升级路线都应参与判断。
- 高压时优先处理即将接触主塔的敌人、持续漏怪和 Boss；压力解除后再补经济、控场、特殊格组合和长期升级。

## 配套资料

- `CommanderAI.TowerReference.json`：塔 ID、当前数值、升级分支、特殊机制和地图格效果。
- `CommanderAI.Level0Reference.json`：默认关卡的地图、生成点、事件、Boss 与规则倍率。
- 指挥官角色 JSON 只能描述角色倾向和决策偏好，不应复制或修改这些权威数值。
